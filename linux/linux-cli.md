# 🐧 PRINCIPALES COMMANDES LINUX

## 📘 AIDE-MÉMOIRE (🔹DE BASE +🔸AVANCÉ)

---

### 🔹 COMMANDES DE BASE

| Commande | Description |
|----------|-------------|
| `ls` | Afficher le contenu d'un répertoire |
| `cd` | Changer de répertoire |
| `pwd` | Afficher le répertoire courant |
| `mkdir` | Créer un répertoire |
| `rmdir` | Supprimer un répertoire vide |
| `cp` | Copier des fichiers ou répertoires |
| `mv` | Déplacer ou renommer des fichiers ou répertoires |
| `touch` | Créer un fichier vide ou mettre à jour les horodatages |

---

### 🔸 PROCESSUS & SURVEILLANCE SYSTÈME

| Commande | Description |
|----------|-------------|
| `ps` | Afficher un instantané des processus en cours |
| `top` | Afficher dynamiquement les tâches Linux |
| `htop` | Visualiseur interactif de processus |
| `nohup` | Exécuter des processus après déconnexion |
| `pstree` | Afficher l'arborescence des processus |
| `bg` | Reprendre un travail suspendu en arrière-plan |
| `fg` | Ramener un travail au premier plan |
| `journalctl` | Interroger et afficher les journaux système |

---

### 🔹 RÉSEAU

| Commande | Description |
|----------|-------------|
| `ping` | Envoyer des paquets ICMP ECHO_REQUEST |
| `curl` | Transférer des données depuis/vers un serveur |
| `wget` | Télécharger des fichiers depuis le web |
| `ssh` | Client OpenSSH (connexion à un hôte distant) |
| `scp` | Copie sécurisée (copie de fichiers à distance) |
| `netstat` | Afficher les connexions réseau |
| `ip` | Afficher/manipuler le routage, les périphériques, les politiques |
| `fail2ban` | Bloquer les IP avec trop d'échecs de connexion |

---

### 🔸 DISQUE & MÉMOIRE

| Commande | Description |
|----------|-------------|
| `df -h` | Afficher l'espace disque libre |
| `du -sh` | Estimer la taille d'un dossier |
| `free -h` | Afficher la mémoire utilisée/libre |
| `lsblk` | Lister les périphériques de type bloc |
| `mount` | Monter un système de fichiers |
| `umount` | Démonter un système de fichiers |
| `lsof` | Lister les fichiers ouverts et les processus qui les utilisent |
| `iostat` | Afficher les statistiques CPU, E/S disque et NFS |
| `rsync` | Synchroniser des fichiers et répertoires |
| `lsyncd` | Synchroniser des répertoires locaux |

---

### 🔹 PERMISSIONS & PROPRIÉTÉ

| Commande | Description |
|----------|-------------|
| `chmod` | Modifier les permissions des fichiers |
| `chown` | Modifier le propriétaire et le groupe d'un fichier |
| `umask` | Masque de permissions par défaut |
| `getfacl` | Afficher les listes de contrôle d'accès (ACL) |
| `setfacl` | Définir les listes de contrôle d'accès (ACL) |
| `sudo` | Exécuter une commande en tant que superutilisateur |
| `su` | Changer d'utilisateur |
| `visudo` | Éditer le fichier sudoers en toute sécurité |
